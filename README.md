# 함께 (가족 귀가·일정 알림판)

가족 귀가·일정 알림판. 주소 하나로 여러 가족이 쓰고, 가족마다 '가족 코드'로 데이터가 나뉩니다.

## 쓰는 가족
1. 주소를 열고 「새 가족 만들기」 → 집 이름·가족 입력 → 시작하기
2. 설정 → 가족 연결 → 「초대 링크 복사」로 가족 초대
3. 휴대폰에서 '홈 화면에 추가'

## 배포하는 사람
1. Firebase 프로젝트 → Firestore(서울, 프로덕션 모드) → 규칙 붙여넣기(앱 설정 화면 또는 설명서 부록)
2. `index.html` 맨 위 `window.FIREBASE_CONFIG`에 설정값, `window.APP_MAKER`에 만든 사람 이름(선택)
3. GitHub Pages 등에 이 폴더의 파일을 올리기

가족 코드는 이 저장소에 적지 마세요.
